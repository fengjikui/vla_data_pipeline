# G1 EDU 数据工程交付计划

已确认：G1 EDU；目标为行走或搬物。未确认：具体自由度、手型、控制器、计算设备、任务验收指标。基于既有预研补充可操作的数据工程手册，保留原 2026-09-12 汇报材料及其数据版本。

| 工作 | 交付 | 完成条件 |
|---|---|---|
| 核对宇树采集、转换与 LeRobot 官方接口 | 固定 commit 的一手证据索引 | 区分遥操作原始格式与训练格式；不推断真机配置 |
| 明确 G1 数据来源与任务边界 | 数据工程手册、采集契约、来源清单 | 行走、导航、上肢、搬运分别说明；列出现有/候选/未支持 |
| 接入 XR JSON + 图片 | importer、字段映射、原始文件保留及转换凭据 | 不猜测关节或单位；不隐式修复时间；失败不发布半成品 |
| 整理训练格式 | 全轨迹 Parquet、带 mask 的 NPZ、惰性读取器、官方 SDK 导出桥 | 本地 batch 可读取；官方桥与核心验收状态分别报告 |
| 存储与版本追溯 | 来源锁、不可改写注册批次、不可变 release、检查点绑定 | 新数据/新规则生成新版本，旧版本校验仍通过 |
| 人工可复现操作 | 逐条命令、检查方法、故障说明、离线/Windows/Linux 路径 | 不需要机器人或大数据下载也能跑完整工程流程 |
| 验收与交付 | 本机测试、既有真实样本复核、小型 CPU 探针、跨平台 CI | 使用保守线程；证据写入新的日期目录；推送 GitHub |

不在此次执行范围：真机连接控制、负载搬运实验、完整预训练 VLA 微调、仿真训练或安装大型仿真环境。对应数据需求与验收流程仍须在文档中给出。
