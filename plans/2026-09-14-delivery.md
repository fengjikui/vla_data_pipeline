# 周一主管汇报交付计划

交付日期：2026-09-14。执行起点：2026-09-12。

## 目标与背景

集团内部 AI 实验室正探索工业具身智能，应用、机器人和预算尚未确定。本次交付用于证明数据工作已从调研进入可复现的工程验证，并为主管决定下一步投入提供依据。机械臂与人形同等展开。

## 工作包及验收

| 工作包 | 可检查产物 | 验收方式 |
|---|---|---|
| 1. 决策汇报 | 主管摘要、约 10 分钟演示材料、讲稿与问答 | 区分发现、实测、建议和未验证能力；讲清需要的决策 |
| 2. 代表性数据 | 真实双臂、真实人形、仿真动作数据的小样本清单 | 来源 revision、SHA256、许可出处、字段与媒体可读 |
| 3. Pipeline MVP | 注册、解析、质检、隔离、去重、切分、归一化、训练视图 | CLI 可重复运行；同源数据不跨 split；统计只用 train |
| 4. 训练接口 | 轻量多模态行为克隆验证程序与检查点 | RGB/语言/状态/动作实际读取；有限 loss/梯度；恢复输出一致 |
| 5. 现场演示 | 离线可读结果、真实样本、异常案例、演示命令 | 已缓存后可断网运行；新增同契约数据可接入 |
| 6. 交付验收 | 自动检查结果、限制清单、4 周路线、GitHub 提交 | README 一步找到材料；未做完整 VLA 或实机验证必须明确 |

## 实施边界

- 不批量下载 TB 级数据，不购买硬件、云算力或商业数据。
- 先做离线批处理和少量来源 reader；新格式或新动作语义首次需要适配。
- 原始动作保留本体差异，不将人形强行改成 7 维机械臂动作。
- 未核实的单位/动作语义明确 unknown；可进入接口验证，但不能宣称可直接部署。
- 用小模型验证数据与训练工程链路，不将训练 loss 下降视为机器人能力提升。
- 本周末交付不以主管先确定工业任务为前提；后续请主管协调工厂交流与资源范围。

## 执行顺序

先固定小样本和数据契约，再实现与验证管线，随后生成由实际输出驱动的汇报材料，最后离线演练、整理文档并推送。阶段事实、命令和限制记录于最终验收报告。


## 2026-09-12 执行结果

六个工作包均形成了可检查产物：16 页汇报及讲稿、三来源小样包锁清单、离线 Pipeline MVP、三组 CPU 训练探针、离线报告和迁移手册。机械臂与人形按同等篇幅给出候选与接口需求。本机原始数据止于约 212 MB，24 项数据的进一步下载留在公司环境按任务筛选。

Ubuntu 24.04 和 Windows 的 21 项测试、CLI 与 wheel 构建已实际通过。当前源码、测试与依赖锁已经推送，汇报与最终验收随交付提交同步。逐项证据和未验证范围见 [最终验收记录](../reports/final-acceptance.md)。

下阶段四周计划属于需要现场与设备资源的研究建议，不属于本次已经完成的 VLA 或机器人能力。
